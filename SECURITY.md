# Segurança / Security

**PT:** este repositório é um catálogo e código de apoio; não opera serviço nem guarda dados de usuários.
Os produtos em `apps/` são código de exemplo **nunca auditado por terceiros** (veja o README de cada um).

Para relatar uma vulnerabilidade (nos scripts, nos workflows ou em um produto de `apps/`), **não abra
issue pública**: use "Report a vulnerability" na aba Security do repositório (aviso privado do GitHub).
Respondemos em até 7 dias. Nunca cole token, senha ou chave em issue, PR ou log; se vazou, revogue primeiro.

**EN:** this repository is a catalog plus supporting code; it runs no service and stores no user data. The
products in `apps/` are sample code **never audited by third parties**. To report a vulnerability, do not
open a public issue: use "Report a vulnerability" in the repository's Security tab. We reply within 7 days.
Never paste tokens, passwords or keys into issues, PRs or logs; if one leaked, revoke it first.
